# Sravani Samavedam — Executive CMA Portfolio

An institutional web dossier and portfolio for **Sravani Samavedam, Qualified Cost and Management Accountant (CMA, ICMAI December 2025)** based in Vijayawada, Andhra Pradesh.

## Stack
- **Framework:** React 18 + Vite + TypeScript
- **Styling:** Tailwind CSS + CSS Custom Properties (Swiss-grid editorial design system)
- **Typography:** Instrument Serif, Plus Jakarta Sans, JetBrains Mono
- **Deployment:** Vercel (Static SPA)

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```

## Deployment to Vercel
1. Import repository `sravani-samavedam` into Vercel.
2. Framework preset: **Vite** (auto-detected).
3. Build command: `npm run build`
4. Output directory: `dist`
5. Click **Deploy**.
